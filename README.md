# IDEAL DMS

A browser-based business document application for Ideal Advanced Design, maintained by Thanatat Sareekham.

## Current version

`IDEAL_DMS_v21.html` is the current local version verified against this repository on 6 October 2026. Earlier version files are retained as development history.

## Features visible in the source

- Quotation and invoice document workflows
- VAT calculations
- CSV import and export
- Browser localStorage persistence
- Backup and restore tools
- Data migrations between application versions

## Technology

HTML, CSS and JavaScript in a browser application.

## Review locally

1. Download or clone the repository.
2. Open `IDEAL_DMS_v21.html` in a modern desktop browser.
3. Use sample business data when reviewing document and import/export workflows.

## Data handling

Business documents are stored in browser localStorage. Back up data before clearing browser storage or changing browser profiles. This repository is source code for review; keep customer records, real invoices and private exports outside Git.

## Project status

An evolving business application. The existence of source code and test files does not imply a complete independent production or security audit.
